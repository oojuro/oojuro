# Bounded managed local residue helper

`record::managed::paged::proof::scan_one` checks one selected original Assigned row against actual stable DATA metadata, a complete callback over future-live Assigned rows and a complete callback over all owned current/orphan/staged DATA file paths. The helper returns only decoded/encoded occurrence counts after both callbacks and every file finish. It neither publishes control nor authorizes unlink, and it cannot prove that caller callbacks supplied a complete current namespace. The managed driver must hold independently current authority, exclusive mutation fencing and exact immutable references around the operation.

Selected patterns reuse the existing native managed `row_strings`/`collect_values` implementation. This covers nonempty agent/text/parent/tool/key strings, attribute names and every typed attribute scalar/container plus raw strings/nested keys. Original protocol IDs/timestamps are not selected payload needles. Empty strings do not create an absence needle; typed containers such as [""] and {"":""} remain explicit nonempty canonical patterns. Shared numeric/bool/null/container data prevents a false zero count even when surviving attribute names differ.

Every live Assigned row is validated and charged in full before one-row Value materialization. All canonical object/array nodes, primitive scalar nodes, raw strings and object keys are scanned. Stable Identity writer/adapter/layout metadata is also scanned even when no live rows remain. Canonical JSON serializes directly into a bounded matcher window; no whole escaped JSON representation or whole live population is retained. Matches may overlap and may occur in multiple canonical ancestor nodes; counts are conservative occurrences, not unique semantic fields or unique physical bytes.

Patterns run one at a time with standard KMP. Its u32 prefix table is exactly one entry per pattern byte, at most64MiB for a legal16MiB selected text. Construction/search fallback steps and table allocation are charged. File reads use one64KiB buffer and constant match state across reads, so matches crossing any buffer boundary and overlapping matches are counted without rescanning giant overlap windows. There is no default automaton construction peak. No entire file is read into memory. One selected-row pattern set, one current prefix table, one live row/Value, serializer state and callback-owned data remain additional bounded workspace, not an exact RSS or allocator zeroization guarantee. Existing native16MiB text/4KiB attrs limits remain; programmatic metadata is restricted to depth40/8192nodes/1024children per container before recursive serialization.

`Work::new(max_bytes,max_rows)` is an explicit trusted operation budget. `charge_bytes`/`charge_rows` let the driver share it with staging, hashing and retirement. Accounting includes full selected/live canonical bytes, raw decoded strings/keys, every repeated file/row pass, prefix tables/construction, extra fallback comparisons and one unit per match. It is conservative work accounting, not storage/billing byte measurement. Any validation, callback, IO or budget failure poisons Work and yields no partial completed Counts. A later caller cannot ignore that failure and use the same Work to report completion.

Each pattern invokes BOTH callbacks afresh: they must reconstruct a COMPLETE immutable iterator on EVERY invocation. This per-selected-row/per-pattern approach repeats live/file scans and canonical ancestors, potentially quadratic or worse in selected population and pattern count; it makes no large-delete throughput or10M/100M claim. A budget refusal must keep completion/absence evidence unavailable. It is a local tracked-namespace check, not a claim about backups, freed blocks, retained caller keys, heap zeroization or irreversible provider deletion. No plaintext pattern/hash is written to disk or returned.

Tests exercise typed shared values and keys, stable identity metadata with zero live rows, exact overlapping/file-buffer-boundary and actual16MiB selected-pattern/file matches, worst escaping streamed canonical nodes, budget poisoning, callback/IO errors, metadata depth and symlink/directory refusal. All8 focused cases passed in0.93s (4.76s incremental build) against the actual private native matcher semantics. A temporary uncommitted child-module test seam was used in this isolated tree; the managed driver owner owns the genuine production module declaration. The seam is removed before handoff. The final ordinary engine Clippy gate (`--lib --tests --no-deps -- -D clippy::all`) passed in3.24s. It retains6 known normal-library unused lower-kernel diagnostics pending genuine managed-driver reachability; this is not a clean `-D warnings` claim. The aliases/test-slice-only mechanical follow-up compiled in that gate; the8-case runtime evidence predates those mechanical changes.


An initial default-Aho implementation passed6 cases but hit its actual180s timeout on the >64KiB pattern case. That result was not acceptance. It was replaced with resource-bounded one-pattern KMP before the final gate; no arbitrary corpus/text limit was lowered to avoid the case.
